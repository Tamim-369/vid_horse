# Asset Index — Dark Psychology Motif Images

Generated via Pollinations (flux). 100 unique images, one per motif. Pick by scene's emotional beat; avoid two adjacent scenes sharing a category.

## Usage guidance
- Match motif to the sentence's *subtext*, not literal words.
- Never repeat a motif within one video; prefer `pick_varied()` from `src/render/motifs.py`.
- Adjacent scenes must differ in category.
- For faces/emotion beats use `face_*`; control/power beats use `control_*`; dread/uncertainty use `shadow_*`/`abstract_*`.
